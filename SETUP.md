# Setup (delete this file when done)

1. Create a **public** repo named exactly `ogore-samwa` (your username) with a README.
2. Upload everything in this folder: `README.md`, `assets/`, and `.github/workflows/` (both files).
3. In `README.md`, replace `REPLACE-WITH-YOUR-HANDLE` (LinkedIn) and `REPLACE-WITH-YOUR-BLOG-URL`.
4. **Settings > Actions > General > Workflow permissions**: choose **Read and write permissions**, Save.
5. **Actions** tab: run **Generate snake** and **Generate 3D contribution graph** once each (Run workflow).
   Until then the snake and 3D graph images show as broken.
6. Hard-refresh your profile after a few minutes; GitHub caches images.
7. Pin your 6 best repos with **Customize your pins**.
